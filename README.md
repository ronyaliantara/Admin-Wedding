# Mahligai Wedding Organizer — Static Web App & PWA Offline (`v21.5`)

Sistem Manajemen Acara Pernikahan, Database Master Kru, Katalog Paket & Perlengkapan Excel, serta Generator Briefing Operasional WhatsApp berbasis **Static Web App + Progressive Web App (PWA) 100% Offline**.

- 🔗 **Link Aplikasi Live (GitHub Pages)**: [https://ronyaliantara.github.io/Admin-Wedding/](https://ronyaliantara.github.io/Admin-Wedding/)
- 📦 **Repository GitHub**: [https://github.com/ronyaliantara/Admin-Wedding.git](https://github.com/ronyaliantara/Admin-Wedding.git)

## Fitur Utama
- **Manajemen Jadwal Acara Pernikahan**: Hitung mundur otomatis (`H-n`), penanda prioritas persiapan (`H-3`), pengarsipan acara selesai, serta pencarian dan filter cepat.
- **Katalog Paket & Logistik Terintegrasi Excel (`.xlsx`)**: Pilih paket pernikahan per area (*Area Sekitar, Gresik, Lamongan, Luar Kota*) atau sisipkan perlengkapan satuan secara instan, lengkap dengan fitur sinkronisasi file `Database_Harvy_Wedding.xlsx`.
- **Database Master Kru & Penugasan Acara**: Kelola kru berdasarkan jabatan (*Asisten, Perias, Fotografer, Sopir Logistik, MC, atau Jabatan Manual*) dan kirim rincian tugas personal langsung ke WhatsApp.
- **Generator Briefing Operasional WhatsApp**: Hasilkan pesan briefing lengkap dan terstruktur untuk grup WhatsApp kru hanya dengan satu klik.
- **100% Offline PWA (Service Worker `v21.5`)**: Dapat diinstal ke layar utama Android, iOS (iPhone/iPad), dan Desktop serta tetap berfungsi penuh tanpa koneksi internet di lokasi acara.
