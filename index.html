Pasang Aplikasi Mahligai WO (PWA)

Arsitektur Static Web App & 100% Offline Tanpa Kuota

⚡ Arsitektur Static Web App + PWA Offline:

Aplikasi ini dirancang sebagai Static Progressive Web App (PWA) mandiri. Setelah dipasang ke layar utama perangkat, seluruh fitur tetap dapat dibuka dan digunakan 100% offline tanpa sinyal internet di lokasi acara.

🤖 Untuk Pengguna Android (Google Chrome):
  1. Buka aplikasi di browser Google Chrome.
  2. Ketuk pop-up "Pasang aplikasi" (Install app) yang muncul otomatis, atau ketuk ikon titik tiga (⋮) di kanan atas Chrome.
  3. Pilih "Pasang aplikasi" atau "Tambahkan ke Layar Utama".
📱 Untuk Pengguna iPhone / iPad (Apple Safari):
  1. Buka aplikasi menggunakan browser Safari.
  2. Ketuk tombol Bagikan / Share (ikon kotak dengan panah ke atas ⎋) di bagian bawah layar.
  3. Geser ke bawah dan pilih "Tambah ke Layar Utama" (Add to Home Screen) ➕, lalu ketuk "Tambah".
💡 Sinkronisasi Data Antar Perangkat: Gunakan menu Pengaturan Admin → Cadangkan Acara (.json) untuk memindahkan jadwal acara antara Laptop dan HP kapan saja secara offline maupun online.
